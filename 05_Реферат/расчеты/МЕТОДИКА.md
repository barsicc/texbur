# Методика воспроизведения учебного примера Леонова

Скважина № 1, шарошечное долото 215,9 СЗ-ГАУ, образец ЛР № 4 от 26.11.2007. Цель — воспроизвести выбор режима по стоимости метра из 26 опубликованных пар нагрузки и частоты. Данные учебные и исторические. Принадлежность пяти рейсов к конкретному промыслу, причины подъёма и актуальность цен не установлены. [Пособие Балицкого и Храбровой, 2-е изд., с. 29–33, 37–38](../../Пособие%20редакция%202%20FIN%20%281%29.pdf#page=37) · [Л04-06, стр. 72–73](../../01_Лекции/Л04-06_Режим_бурения.pdf#page=72).

Выходы $\overline V_m,V_r$ в м/ч, $H$ в м, $t,T$ в ч, $C$ в руб./м. $t$ — механическое время рейса, использованное для калибровки длительности отработки. Образец называет его среднее «стойкостью». Для вывода о ресурсе опоры или вооружения нужны причины и условия подъёма.

## Калибровка и три формы расчёта

Из исходных строк $\sum H_i=750$ м, $\sum t_i=121$ ч, $N=5$. Фиксируем показатели (4.2)–(4.3) из пособия и вычисляем $H_*=\sum H_i/N=150$ м, $t_*=\sum t_i/N=24{,}2$ ч, $V_*=\sum H_i/\sum t_i=750/121$ м/ч. Скорость получается взвешиванием $H_i/t_i$ по времени каждого рейса. Пять рейсов при одних $P,n$ дают два масштабных коэффициента и не позволяют оценить четыре степени. При чтении (4.6) берём $t_*$ из (4.9) согласно (4.3) и строкам с. 37. Буква $t_в$ в (4.6) и единица «ч» для $H_*$ на с. 31 явно отмечены как расхождения записи. [Пособие, с. 30–32](../../Пособие%20редакция%202%20FIN%20%281%29.pdf#page=30).

1. **Исходная форма.** В $(P_0,n_0)$ положим $k=V_*/(P_0^{p_v}n_0^{q_v})$, $A=t_*P_0^{p_t}n_0^{q_t}$. Тогда $\overline V_m=kP^{p_v}n^{q_v}$, $t=A/(P^{p_t}n^{q_t})$, $H=\overline V_m t$.
2. **Относительная форма.** Поделив выражения для скорости и времени на соответствующие выражения в опоре и обозначив $x=P/P_0$, $y=n/n_0$, получаем $\overline V_m=V_*x^{p_v}y^{q_v}$, $t=t_*x^{-p_t}y^{-q_t}$, $H=H_*x^{p_v-p_t}y^{q_v-q_t}$. В обеих реализациях $s=t_{\mathrm{сп}}+t_{\mathrm{всп}}$, $T=t+s$, $V_r=H/T$, $C=(C_b+C_h T)/H$.
3. **Разложение стоимости.** Разбиваем числитель на $C_h t$ и $C_h s+C_b$. Тогда $C=C_h/\overline V_m+(C_h s+C_b)/H$. С учётом исходной формы $H=kA P^{p_v-p_t}n^{q_v-q_t}$ получаем (4.4), то есть $B/(P^{p_v}n^{q_v})+(D+M)/(P^{p_v-p_t}n^{q_v-q_t})$. Здесь $B=C_h/k$, $D=C_hs/(kA)$, $M=C_b/(kA)$. В главном расчёте коэффициенты вычисляются без промежуточного округления.

Для каждой ячейки сохраняются значения двух форм, стоимость по $B,D,M$, печатная стоимость и подписанный остаток $C_{\mathrm{расч}}-C_{\mathrm{печат}}$. Сравнение с порогом 0,12 руб./м идёт по абсолютному остатку до округления. Порог установлен после наблюдения остатка именно в этой регрессионной сверке. Для подсчёта совпадений при печатной точности применяется округление до десятой по ближайшему значению с округлением точной половины вверх для положительных стоимостей. Отдельный диагностический столбец заменяет только $D$ величиной 36106,83 из F30 с. 37. [Приёмка этапа 1](../проверка/ПРИЁМКА_ЭТАПА_1.md) · [Математический аудит](../проверка/МАТЕМАТИЧЕСКИЙ_АУДИТ.md).

## Ограничения и сетка

В рамках образца $P_{\min}\le P\le P_{\max}$ и $40\le n\le n_{\lim}(P)$, где

$$
n_{\lim}(P)=80+(40-80)\frac{P-130000}{220000-130000}.
$$

Проверка допустимости выполняется на точных рациональных числах. Целое число в столбце L пособия служит для отображения, например 49 при 200 кН скрывает точный предел $440/9<49$. В строках перебора используются фактически напечатанные 130, 150, 170, 190 и 200 кН, в столбцах 40–80 об/мин с шагом 5 об/мин. Из 45 пар 26 допустимы. С. 32 описывает шаги 20 кН и 10 об/мин, вставку частот на границе и пределы 50 и 90 % паспортного максимума нагрузки. Для 220 кН эти доли дают 110 и 198 кН. Сетка на с. 38 следует собственной разметке с шагом нагрузки 10 кН между последними двумя строками. Формула (4.10) и образец воспроизводятся как опубликованы. [Пособие, с. 32–33, 38](../../Пособие%20редакция%202%20FIN%20%281%29.pdf#page=32).

На графике чувствительности меняется один параметр в пределах того же учебного ограничения: $130\le P\le175$ кН при $n=60$ об/мин и $40\le n\le640/9$ об/мин при $P=150$ кН. Отсчёт ведётся от опорного режима, шкала безразмерная. График стоимости окрашивает только вычисленные узлы. На нём отдельно показаны допустимая дробная частота при 190 кН и недопустимая пара 200 кН / 50 об/мин. Полный непрерывный поиск в расчёт не включён.

## Воспроизведение

Команды из корня репозитория. Расчёт и проверка используют стандартную библиотеку Python 3.10+. Для рисунков использован Matplotlib 3.10.8, штатный шрифт DejaVu Sans и вывод без графического интерфейса.

~~~bash
python -B 05_Реферат/расчеты/скрипты/leonov.py
python -B -m unittest discover -s 05_Реферат/расчеты/скрипты -v
python -B 05_Реферат/расчеты/скрипты/plot_leonov.py
~~~

Скрипт расчёта принимает путь записи через аргумент `--output`, скрипт графиков — путь результатов `--results` и каталог иллюстраций `--output-dir`. Каждый запуск использует один файл исходных данных. JSON сохраняет числа без расчётного округления в пределах машинной точности. [Результаты JSON](RESULTS.json) · [Таблица и рисунки](ИТОГИ.md).
