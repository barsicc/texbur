# Глава 2. Построение и классификация математических моделей механического бурения

**Задача.** Связать форму модели с типом результата и критерием, который она позволяет оценить. Объём 5,2 страницы. Пользоваться показателями главы 1 по отсылке к § 1.3. [План](../ПЛАН.md) · [Источники и страницы](../КАРТА_ЦИТИРОВАНИЯ.md).

| Раздел | Что написать | Проверенные опоры |
|---|---|---|
| 2.1 · 1,6 стр. | Показать средние и накопленные результаты рейса, скорости изменения состояний и начальные условия. Пример сочетания — F04 для $H(t)$ и F07 для верхней границы по стойкости. В схеме показать, где входят $P,n,Q$ и условия $\boldsymbol z$. | F10, [1, PDF с. 64–71, 26, 34]. Рисунок 3. |

| 2.4 · 1,0 стр. | Пояснить условие $H'(t)=H(t)/(t+s)$, смещение времени для двух критериев и проверку концов допустимого интервала. Связать выход модели и данные с задачей главы 3. | F03–F04 и предел F07, [1, PDF с. 25–35, 62–66]. |

Для Леонова фиксированы $p_v=1{,}4$, $q_v=0{,}8$, $p_t=1{,}2$, $q_t=0{,}7$. Эластичности проходки 0,2 по нагрузке и 0,1 по оборотам при прочих равных в режиме модели. Однорежимные рейсы дают масштабы при заданных степенях. Чтобы оценить степени отдельно, нужна раздельная вариация $P,n$, сопоставимые условия и проверка на других данных. Атрибуция Леонова по лекции и пособию.

Для Бадалова использовать $V'=-\lambda_k V^k$ и область принятого решения F08. Размерность $\lambda_k$ равна $[V]^{1-k}/[t]$. Для F04 нужны $V_0>0$ и $\lambda>0$ в ч⁻¹. В частном экспоненциальном случае уравнение для положительной стационарной точки при $s>0$ сохранено в F04. Для самой идеи необходимости границ достаточно одного пояснения, без вычисления отдельного примера. В F03 для рейсовой скорости $s=t_{\mathrm{сп}}+t_{\mathrm{всп}}$, для стоимости добавляется $C_b/C_h$. Проверять существование внутренней точки и сравнивать с границами, в том числе с пределом стойкости, если он известен.

**Граница главы.** Вводные показатели берутся из главы 1. Пример комбинации является рабочей иллюстрацией классификации, на слайдах собственная формула комбинированного типа отсутствует. Формы долотных уравнений остаются в главе 3. Числа опоры, точная область и её перебор — в главе 4. По времени обсуждается отработка при фиксированном режиме, по сетке — иной вопрос выбора $P,n$.
