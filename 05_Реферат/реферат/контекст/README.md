# Авторские комплекты

Комплекты приняты по SHA 13fb80c7c65467f68f51f5009fd9472a2896dff8. Работу над главами разрешено начать в одной новой сессии Codex. Передайте исполнителям ссылку на принятую версию и назначьте каждой задаче отдельный исходник и комплект. Оркестратор получает один интегрированный результат с перечнем открытых вопросов.

| Задача | Размер по плану | Владелец содержания |
|---|---:|---|
| [Глава 1](ГЛАВА_1.md) | 3,8 стр. | Физика, исходная терминология и показатели |
| [Глава 2](ГЛАВА_2.md) | 4,4 стр. | Формы моделей, Леонов, Бадалов и выбор критерия |
| [Глава 3](ГЛАВА_3.md) | 4,0 стр. | ROP, прочность, геометрия, калибровка и ГТИ |
| [Глава 4](ГЛАВА_4.md) | 4,6 стр. | Данные, расчёт, проверка и интерпретация кейса |

Общий вход для каждого автора — [план](../ПЛАН.md), [стандарт текста](../СТАНДАРТ_ТЕКСТА.md), [карта цитирования](../КАРТА_ЦИТИРОВАНИЯ.md), [иллюстрации](../ПЛАН_ИЛЛЮСТРАЦИЙ.md), [F01–F19](../../теория/РЕЕСТР_ФОРМУЛ.md) и [приёмка этапа 2](../../проверка/ПРИЁМКА_ЭТАПА_2.md). При необходимости открыть оригинал на указанной странице. Исходник главы содержит заголовки плана, текст с квадратными ссылками, редактируемый исходник формул, отсылки к рисункам и подготовленные таблицы. Существенный вопрос записать отдельно для редактора с местом и основанием.

После приёмки предлагается использовать четыре задачи с раздельными файлами. Главы 1 и 2 закрепляют общие определения, но остальные авторы могут сразу работать по принятому реестру. При доступной и явно разрешённой работе с отдельными агентами задачи выполняются параллельно. Иначе выполнить их последовательными проходами в одной сессии. Один редактор интегрирует главы, сверяет входы и выводы подразделов, закрепляет ссылки и нумерацию, пишет введение и заключение. Изменение утверждённой формулы, единицы, границы или значения вынести оркестратору с документированным основанием и затронутыми местами.

Для введения взять 0,9 стр. и сформулировать цель, механические границы темы, задачи и способ проверки. Для заключения взять 0,8 стр. и закрыть задачи конкретными выводами о моделях и кейсе, сохранив границы применимости. Обе части увязать после сведения глав, используя строки карты цитирования. Подготовка отдельной сессии для каждой главы студенту не требуется. [Регламент](../../ORCHESTRATION.md) · [Сборка](../ОФОРМЛЕНИЕ.md).
