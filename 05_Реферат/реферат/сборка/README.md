# Сборка черновика этапа 4

[Исходники текста](../текст) собираются в порядке от `00_титул.md` до `07_литература.md`. PDF экспортируется из того же DOCX. Итоговые файлы находятся в [каталоге черновиков](../черновик). Уравнения записаны в LaTeX и преобразуются Pandoc в редактируемые объекты OMML. Номера добавляются отдельно на правую табуляцию. Содержание содержит поле Word TOC и рассчитанные номера страниц с внутренними ссылками. При повторной сборке скрипт извлекает номера страниц заголовков из экспорта, заново заполняет содержание и сверяет разбиение. В Word после самостоятельной правки обновите поле содержания целиком.

Для воспроизведения нужны Pandoc 3.x, LibreOffice Writer с командой `soffice`, Times New Roman, Python 3 и пакеты `python-docx`, `PyMuPDF`, `matplotlib`, `numpy`. При необходимости путь к Writer передаётся через `--office` или `TEXBUR_SOFFICE`. Скрипт рисунков пишет семь SVG и семь PNG с разрешением 300 dpi. Рисунки 6–7 используют принятые данные и функции построения этапа 2, с изменением компоновки для печати.

Команды из каталога `05_Реферат/реферат`:

~~~sh
python сборка/figures.py
python сборка/build.py --output-dir черновик
python сборка/build.py --control --output-dir /путь/к/временному/каталогу
~~~

Контроль объёма использует те же стили и экспорт, с фильтром `text_only.lua`. В контрольную копию входят введение, главы и заключение, с заголовками и формулами. Фактический шрифт проверяется через `fc-match 'Times New Roman'` и `pdffonts`. Версии инструментов, результаты объёмной и визуальной проверок приведены в [аудите этапа 4](../../проверка/АУДИТ_ЭТАПА_4.md).
