# ЛР — лабораторные работы

Папка только для лабораторных.

- `Пособие_ЛР_Балицкий_Храброва_2007.pdf` — методичка со всеми ЛР №1–8 (93 стр.). ЛР4 — стр. 29–39, приложение (нормы СПО, допустимые P и n долот) — стр. 81–89.
- `ЛР4/` — **защита ЛР №4** «Выбор оптимального режима и рационального типа шарошечного долота при роторном способе бурения»:
  - `ЛР4_защита.md` — ответы на 10 контрольных вопросов (формулы + графики);
  - `ЛР4_защита.pdf` — то же в PDF (для телефона/печати, всё отображается);
  - `рисунки/` — 6 графиков; `src/figures.py` — их генератор (пересчитывает образец ЛР), `src/build_pdf.sh` — сборка PDF.
- `рисунки_пособия/` — страницы пособия с формулами и образцом ЛР4.
