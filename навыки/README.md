# Навыки по бурению

Каждый навык описывает исходные данные, порядок работы и проверки. Для выбора метода по теме начни с [карты курса](../КАРТА.md#как-темы-связаны). Для поиска конкретной формулы открой [указатель](../ФОРМУЛЫ.md).

| Навык | Что позволяет сделать |
|---|---|
| [Анализ колебаний бурильной колонны](анализ-колебаний-бк/SKILL.md) | Распознавать stick-slip, рассчитывать частоты продольного возбуждения и проверять резонансные обороты по материалам курса бурения. |
| [Подбор элементов БК и КНБК](выбор-бк-и-кнбк/SKILL.md) | Читать схему бурильной колонны, обосновывать подбор её элементов и перечислять проверки по способу бурения и условиям ствола. |
| [Контроль режима по ГИВ, ЗТС и ГТИ](измерения-на-буровой/SKILL.md) | Определять осевую нагрузку по ГИВ, читать круговую диаграмму и выбирать источник данных о режиме бурения по семинару С02. |
| [Свойства горных пород и классификационный разрез](определение-свойств-пород/SKILL.md) | Читать диаграммы вдавливания штампа, получать категории свойств пород и строить МКР для предварительного выбора шарошечных долот. |
| [Проектирование конструкции скважины](проектирование-конструкции-скважины/SKILL.md) | Учебный расчёт конструкции скважины по интервалам давления, выбор глубин обсадки, диаметров долот и труб, интервалов цементирования. |
| [Расчёт прочности бурильной колонны](прочность-бурильной-колонны/SKILL.md) | Рассчитать секции бурильной колонны на растяжение, проверить совместное действие изгиба и кручения и определить запас выносливости по материалам курса. |
| [Расчёт тангенциального профиля ННС](расчёт-профиля-ннс/SKILL.md) | Расчёт трёхучасткового тангенциального профиля наклонно-направленной скважины с постоянным азимутом, подбор допустимой кривизны и проверка выхода в цель. |
| [Расчёт утяжелённых бурильных труб](расчёт-убт/SKILL.md) | Рассчитать число ступеней, длины и погружённый вес УБТ в учебной задаче, сверить компоновку со слайдами и расчётным примером. |
| [Выбор долота и режима бурения](режим-бурения/SKILL.md) | Разбить разрез на пачки одинаковой буримости, выбрать тип долота и сравнить допустимые параметры режима по рейсовой скорости или затратам. |
| [Секционный расчёт бурильной колонны](секционный-расчёт-бк/SKILL.md) | Выполнять учебный статический расчёт секций бурильных труб в вертикальной скважине с забойным двигателем, проверять клиновой захват и выбирать моменты свинчивания. |
