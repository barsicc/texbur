# Загрузка материалов курса

Сюда можно загрузить 13 файлов с портала одним пакетом: семь файлов лекций и шесть файлов семинаров, включая теорию и пример расчёта УБТ. Оставляйте исходные имена файлов, чтобы их можно было сверить со списком портала.

После проверки материалы будут распределены по папкам `01_Лекции` и `02_Семинары`.
