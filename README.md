# texbur — Бурение нефтяных и газовых скважин

Материалы курса (РГУ нефти и газа им. И.М. Губкина, кафедра бурения НГС): лекции, семинары, справочники к ДЗ.

- **[Темы курса](темы/README.md)** — понятия, связи, различия и ссылки на страницы оригиналов.
- **[КОНТРОЛЬНАЯ.md](КОНТРОЛЬНАЯ.md)** — быстрые ссылки на формулы, графики, расчётные примеры и разделы пособия.
- **[навыки/](навыки/)** — пошаговые учебные методики и проверки расчётов.
- **[КАРТА.md](КАРТА.md)** — навигатор: все файлы, темы → страницы, каталог рисунков.
- **[ФОРМУЛЫ.md](ФОРМУЛЫ.md)** — все формулы со ссылками на слайды.
- **[конспекты/](конспекты/)** — полные транскрипции лекций, семинара и справочников.
- `01_Лекции/`, `02_Семинары/`, `03_ДЗ/`, `04_Литература/` — исходные файлы.
- `рисунки/` — картинки ключевых слайдов.

Новые файлы с портала можно загрузить в [00_Загрузки/](00_Загрузки/).
