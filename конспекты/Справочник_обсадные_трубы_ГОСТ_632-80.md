# Справочник: трубы обсадные и муфты к ним (ГОСТ 632-80)

**Источник:** `03_ДЗ/Трубы_обсадные_и_муфты_ГОСТ_632-80.docx` (из папки ДЗ на портале). Ссылка в файле: http://www.cskz.ru/UserFiles/File/GOSTs/Trub/gost632-80.pdf
**Для чего:** ДЗ-1 — подбор колонн: наружный диаметр **муфты** $D_н$ → $D_B = D_н + 2\Delta$; **внутренний** диаметр $d$ → проверка $d \ge D_B + 2\delta$ (см. `конспекты/С01_...md`, стр. 11–16).

Обозначения: $D$ — наружный диаметр трубы, $s$ — толщина стенки, $d$ — внутренний диаметр ($d = D - 2s$), $D_н$ — наружный диаметр муфты (в скобках — вариант для исполнения с увеличенным/спец. диаметром муфты), $D_с$ — наружный диаметр муфты специального (уменьшенного) исполнения, $L_м$ — длина муфты. Размеры в мм.

> ⚠️ В исходном docx есть опечатки. Я проверил каждую строку по формуле $d = D - 2s$ (и массы по $m ≈ 0{,}02466(D-s)s$). Исправленные значения помечены **✎**, в скобках — как было в исходнике.
