## 3. Классификация (разд. 3)
**Виды:** I — одношарошечные; II — двухшарошечные; III — трёхшарошечные.

**Типы (по породам):**
| Тип | Вооружение | Породы |
|---|---|---|
| М | стальные зубья | мягкие |
| МЗ | твердосплавные зубки | мягкие абразивные |
| МС | стальные зубья | мягкие с пропластками средней твёрдости |
| МСЗ | тв. зубки | мягкие абразивные с пропластками средней твёрдости |
| С | стальные зубья | средней твёрдости |
| СЗ | тв. зубки | абразивные средней твёрдости |
| СТ | стальные зубья | средней твёрдости с пропластками твёрдых |
| Т | стальные зубья | твёрдые |
| ТЗ | тв. зубки | твёрдые абразивные |
| ТК | стальные зубья + тв. зубки | твёрдые с пропластками крепких |
| ТКЗ | тв. зубки | твёрдые абразивные с пропластками крепких |
| К | тв. зубки | крепкие |
| ОК | тв. зубки | очень крепкие |

**Промывка/продувка:** Ц — центральная промывка; Г — боковая гидромониторная; ЦГ — комбинированная; П — центральная продувка; ПГ — боковая продувка.

**Опоры шарошек:**
- **В** — подшипники качения + (один или более) упорных скольжения или без них; **ВУ** — то же, герметизированная;
- **Н** — один радиальный скольжения + упорные скольжения (остальные — качения); **НУ** — то же, герметизированная;
- **А** — два и более радиальных скольжения + упорный скольжения; **АУ** — то же, герметизированная.

**Условное обозначение (пример):**
`Долото шарошечное III 215,9 СЗ-ГАУ ГОСТ 20692-2003` — трёхшарошечное, Ø 215,9 мм, абразивные породы средней твёрдости, боковая гидромониторная промывка, опора АУ.

## 4. Технические требования (разд. 4) — главное
- Резьба — **правая коническая замковая**. З-42, З-63,5 — по ТД; З-50 — ГОСТ 7918; остальные — ГОСТ 28487 (в РФ — ГОСТ Р 50864-96).
- Натяг ниппельной резьбы: З-42 — 10,35⁺⁰·⁴; З-50 — 10,00⁺⁰·⁴; З-63,5 — 16,00⁺⁰·⁴; З-88…З-201 — 15,875 мм; муфтовые З-88…З-201 — 0.
- Герметичность промывки гидромониторных долот: **Ø ≥ 190,5 мм — 7,85 МПа; < 190,5 — 5 МПа** (п. 4.5); насадки удерживаются при тех же давлениях и **должны быть сменными** (п. 4.6).
- Срок сохраняемости — **≥ 18 мес** (п. 4.15.1). Опоры заполнены смазкой; АУ и ВУ вакуумируют перед заполнением (п. 4.12).
- Маркировка на торце ниппеля: товарный знак, обозначение, (резьба), номер, дата, клеймо ОТК. Паспорт — в т.ч. код **IADC** (по требованию).
- Табл. 2 — допуски на разновысотность шарошек и радиальное биение по группам диаметров (76–98,4; …; >490) и типам — см. docx при необходимости.

## 5. Приёмка, контроль, хранение (разд. 5–8)
- Приёмосдаточные испытания по ГОСТ 15.309; 100 % по большинству пунктов, 10 % по сварным швам (п. 4.7).
- Диаметр — **предельными калибрами-кольцами**; натяг — резьбовыми калибрами; герметичность — опрессовкой 20 с на гидростенде.
- Хранение — сухие закрытые помещения, условия 6 (ОЖ2) по ГОСТ 15150.
- Свинчивание с бурильной трубой — с помощью спецприспособления (по форме долота) и машинного ключа.
