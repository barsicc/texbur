# Работа с texbur

Отвечай на русском. Для вопросов по курсу используй [CLAUDE.md](CLAUDE.md), [темы курса](темы/README.md), [карту материалов](КАРТА.md) и [навигатор к контрольной](КОНТРОЛЬНАЯ.md). В решениях указывай источник и страницу. Для расчётной задачи используй [каталог навыков](навыки/README.md). Формулы в новых конспектах сверяй с изображениями оригинала и отмечай расхождения со слайдами.

## Коммиты и отправка на GitHub

- После каждой задачи, в которой ты меняешь файлы, проверь изменения, сделай коммит только с правками по задаче и сразу отправь его в `origin/main`. Владелец репозитория разрешает коммит и пуш без повторного подтверждения. Соблюдай явно указанные исключения для текущей задачи.
- Чужие локальные правки не включай. Если `main` защищена, отправь изменения в отдельную ветку и пришли ссылку на неё.
- В финальном ответе укажи ветку и SHA коммита. Если пуш не прошёл, укажи точную причину.

## Исключение: проект реферата Балицкого

На ветке `referat-2026` для реферата действуют [AGENTS.md проекта](05_Реферат/AGENTS.md), [паспорт](05_Реферат/PROJECT.md), [требования](05_Реферат/REQUIREMENTS.md), [правила оркестрации](05_Реферат/ORCHESTRATION.md), [журнал решений](05_Реферат/DECISIONS.md) и [статус](05_Реферат/STATUS.md). Читай их **перед любой задачей по реферату**, даже в новой сессии из корня. Для реферата правило отправки в origin/main выше НЕ действует: только обычный push в origin/referat-2026, без force и без изменения main. Не переходи к следующему этапу без явной приёмки главного оркестратора. Не изменяй существующие учебные материалы без разрешения.
